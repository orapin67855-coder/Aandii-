# เชื่อมโมเดล AI เข้าติวเตอร์ (ใช้ฟรีได้)

ข้อความว่ายังไม่ได้ตั้งค่า `AI_API_KEY` หมายถึงยังไม่มีคีย์ AI ฝั่งเซิร์ฟเวอร์ ทำตามนี้:

1. เข้า https://aistudio.google.com/apikey ล็อกอินด้วยบัญชี Google แล้วกดสร้างคีย์ (free tier ไม่ต้องผูกบัตร)
2. ใส่ใน `.env.local` และใน Environment Variables ของ Vercel **ฝั่งเซิร์ฟเวอร์เท่านั้น** ห้ามขึ้นต้นด้วย `NEXT_PUBLIC_`:
   ```
   AI_API_KEY=คีย์ที่ได้
   AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai
   AI_MODEL=gemini-3.8-flash
   AI_FALLBACK_MODEL=gemini-3.5-flash-lite
   AI_GLOBAL_DAILY_LIMIT=200
   TUTOR_DAILY_LIMIT=40
   ```
3. รีสตาร์ตเซิร์ฟเวอร์ แล้วลองถาม `2+2` และถ่ายรูปโจทย์

แอปนี้ยังไม่มีโปรเจกต์ Supabase จึงนับโควตาต่อคนและทั้งระบบในที่เก็บเดิม (`tutor.json` / Blob) ตามเวลาไทย ไฟล์ `supabase/migrations/0005_tutor_global_limit.sql` เป็นแบบอ้างอิงไว้ตอนย้ายฐานข้อมูล

## ข้อควรรู้ก่อนใช้กับนักเรียนจริง
- Free tier ของ Google: เนื้อหาที่ส่งไปอาจถูกใช้ปรับปรุงผลิตภัณฑ์ของ Google (ตามหน้า Pricing ของ Gemini API ที่ตรวจเมื่อ 21 ต.ค. 2569) ส่วน paid tier ระบุว่าไม่ถูกนำไปใช้ ทดลองกับทีมได้ แต่ถ้าเปิดให้นักเรียนทั่วไป โดยเฉพาะผู้ใช้ต่ำกว่า 18 ปี และมีรูปถ่าย ควรย้ายไป paid หรือใช้ผู้ให้บริการที่ไม่ใช้ข้อมูลฝึกโมเดล และต้องระบุในนโยบายความเป็นส่วนตัว
- ชื่อรุ่นและโควตาฟรีเปลี่ยนบ่อย จึงตั้งชื่อรุ่นผ่าน env และมีรุ่นสำรอง ถ้าโดน 429 ระบบจะลองรุ่นสำรอง แล้วบอกผู้ใช้ให้รอสักครู่
- เปลี่ยนผู้ให้บริการได้โดยแก้ `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` ขอแค่รองรับรูปแบบ OpenAI chat/completions พร้อม tool calling และรับรูป
- รูปที่ผู้ใช้ส่งถูกย่อเป็น JPEG และตัด EXIF ในเครื่อง ไม่เก็บตัวรูปลงฐานข้อมูล
